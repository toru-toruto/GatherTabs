# Gather Tabs

開いているすべての Chrome ウインドウのタブを、いまのウインドウ 1 つにまとめる Chrome 拡張（Manifest V3）。タブは閉じずに移動する。

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

## 使い方

- 集め先にしたいウインドウで、ツールバーの拡張アイコンを押す
- ショートカットは `Alt+Shift+G`（Mac は `Option+Shift+G`）。`chrome://extensions/shortcuts` で変更できる

## 挙動

- 他のウインドウのタブを、集め先のタブ列の末尾に元の並び順で移動する
- 固定タブは固定したまま移動する
- タブグループはグループごと移動する
- タブがなくなった移動元ウインドウは自動で閉じる

## 制限

- 通常ウインドウとシークレットウインドウの間ではタブを移動できないので、集め先と同じ種類のウインドウだけを対象にする
- ポップアップ型ウインドウと PWA のウインドウは対象外
- ドラッグ中のタブなど、移動できなかったタブは元のウインドウに残る

## 構成

```
manifest.json
background.js   アイコンのクリックを受けてタブを移動する service worker
icons/          ツールバーと拡張一覧のアイコン
```
